A nav bar for modern apps.

Scroll down and the floating bar shrinks to icons. Scroll up and the labels come back. Drop it into the tab navigator you already have. It animates on the UI thread, on iOS and Android.

Drop-in

Pass it as tabBar to React Navigation or Expo Router. It reads the icons, labels and badges you already set.

Smooth where it counts

Transforms and opacity only, on the UI thread. On an Android release build it janked no more than the stock tab bar, even with the JS thread blocked.

Yours to shape

Colours, sizes, scroll thresholds, animation, placement, an action button. Start from a preset and change what you like with combine().

Scrub to switch

Drag along the bar and the indicator follows your finger. Let go to switch. Hook a haptic tick to each tab you pass.

Glass when it's there

Real Liquid Glass on iOS 26, a system blur on older iOS, and a clean frosted fill on Android. One import.

The details, done

Right-to-left layouts, screen-reader labels, badges, the keyboard and safe areas are handled for you.

Two steps

Use it as the tab bar, then let each scrollable screen tell it when you scroll.

Read the full docs → 
// 1. Use it as the tab bar
import { ShrinkingTabBar } from 'react-native-shrinking-tab-bar';

<Tabs tabBar={(props) => <ShrinkingTabBar {...props} />} />

// 2. Connect your lists
const onScroll = useShrinkingTabBarScrollHandler();
const inset = useShrinkingTabBarInset();

<Animated.FlatList
  onScroll={onScroll}
  scrollEventThrottle={16}
  contentContainerStyle={{ paddingBottom: inset }}
/>
