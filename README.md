# react-native-shrinking-tab-bar

Floating pill tab bar for React Navigation that shrinks to icons on scroll down and expands on scroll up

## Installation


```sh
npm install react-native-shrinking-tab-bar
```


## Usage


```js
import { multiply } from 'react-native-shrinking-tab-bar';

// ...

const result = multiply(3, 7);
```
