# Support

- **Questions and how-tos:** start with the [README](README.md), especially [Troubleshooting](README.md#troubleshooting). If that doesn't answer it, open a discussion.
- **Bugs:** open an issue with the bug report form and include a minimal reproduction.
- **Feature ideas:** open an issue with the feature request form.
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't report them in public issues.
